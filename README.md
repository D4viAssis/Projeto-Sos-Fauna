# SOS FAUNA

Site informativo sobre proteção da fauna silvestre, desenvolvido com Vue 3,
JavaScript, Vite e Vue Router.

## Executar localmente

1. Instale o Node.js (versão LTS).
2. Na pasta do projeto, instale as dependências:

   ```sh
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```sh
   npm run dev
   ```

Abra no navegador o endereço mostrado no terminal.

## Rotas iniciais

- `/` — página inicial.
- `/sobre` — informações sobre a SOS FAUNA.
- `/orientacoes` — cuidados ao encontrar animais silvestres.
- `/ajuda` — canais de atendimento e informações para comunicar uma ocorrência.
- `/faq` — respostas para dúvidas frequentes.
- `/login` — espaço reservado para a tela de login.
- `/cadastro` — espaço reservado para a página de cadastro.

Os arquivos de imagem do site devem ficar em `public/assets/images/`.
